# Casos

Cada vez que uma análise curada cai num registro de `leituras-regionais.md`, o caso entra aqui, no topo da tabela. A rotina das 6h acrescenta os casos que encontra no PR do feed, e os curadores podem registrar casos pelo portal. A rotina copia para cá os casos novos do portal e para o portal os casos daqui, sem repetir o mesmo link.

Quando um registro acumula casos de um mesmo autor, a recorrência vai para a seção "Para revisar" da edição, para Thiago decidir se o caso segue ao Conselho.
